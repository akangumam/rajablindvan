# Logo Assets

## Aplikasi Logo

-   **Radja-Blind-Van-Logo.png** - Logo utama aplikasi untuk sidebar dan header
-   Format: PNG dengan background transparent
-   Ukuran optimal: 120x40px atau sesuai aspect ratio

## Cara Replace Logo:

1. Siapkan file `Radja-Blind-Van-Logo.png`
2. Copy ke folder `public/assets/images/`
3. Logo akan otomatis muncul di sidebar aplikasi

## Spesifikasi Logo:

-   Format: PNG/SVG
-   Background: Transparent/White
-   Ukuran: Flexible (akan di-resize otomatis)
-   Aspect ratio: Dipertahankan
