Fitur Multi-Bahasa

Aplikasi Radja Blind Van kini mendukung 2 bahasa!

✨ NEW FEATURE

Language Switcher

Klik salah satu tombol di bawah untuk mengganti bahasa aplikasi:

Cara Kerja: Pilihan bahasa disimpan di session browser. Setelah switch, seluruh aplikasi akan tampil dalam bahasa yang dipilih.

Fitur yang Tersedia

  • Navigation Menu - Semua menu sidebar otomatis terjemahkan
  • Quick Add Modal - Tombol tambah cepat dalam bahasa pilihan
  • Vehicles Module - Label field, tipe kendaraan, jenis BBM
  • Customers Module - Semua field pelanggan
  • Reports Module - Filter, periode, export buttons
  • Reminders Module - Kategori, status, pesan
  • Form Actions - Tombol Simpan, Batal, Hapus, dll
  • Messages - Success, error, warning messages

Contoh Implementasi

1. Penggunaan di Blade Template
<h1>{{ __('common.dashboard') }}</h1> <button>{{ __('common.add') }}</button> <a href="#">{{ __('vehicle.add_vehicle') }}</a>
2. Hasil Output
Translation Key 🇮🇩 Indonesia 🇬🇧 English
common.dashboard Dasbor Dashboard
common.vehicles Kendaraan Vehicles
common.add_new Tambah Baru Add New
vehicle.license_plate Plat Nomor License Plate
report.total_revenue Total Pendapatan Total Revenue
3. File Translation
resources/lang/ ├── id/ # Bahasa Indonesia │ ├── common.php # Teks umum │ ├── vehicle.php # Modul kendaraan │ ├── customer.php # Modul pelanggan │ ├── report.php # Modul laporan │ ├── reminder.php # Modul pengingat │ └── quick_add.php # Quick add modal └── en/ # English ├── common.php ├── vehicle.php ├── customer.php ├── report.php ├── reminder.php └── quick_add.php

Routes & Technical Details

Routes untuk Language Switching
// Switch ke Bahasa Indonesia GET /locale/id // Switch ke English GET /locale/en
Komponen Teknis
  • LocaleController - Handle language switching logic
  • SetLocale Middleware - Set locale untuk setiap request
  • Session Storage - Simpan pilihan bahasa user
  • Translation Files - 6 file x 2 bahasa = 12 file
